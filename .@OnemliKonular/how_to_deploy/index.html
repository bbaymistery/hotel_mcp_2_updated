1 · Lokalde ayağa kaldırma

Gereken

Node.js 22 (sende v22.23.3 kurulu) ve kök klasörde bir .env dosyası. Sende .env zaten var. Şu anahtarları içermeli:

DATABASE_URL="postgresql://...neon.tech/neondb?sslmode=require"   # zorunlu
GEMINI_API_KEY="..."                                              # sadece chat widget için
GEMINI_MODEL="gemini-2.5-flash"                                   # opsiyonel
PORT=3001                                                         # opsiyonel, varsayılan 3001

İlk kurulum (bir kere)

  1. Backend bağımlılıkları. Bu komut sonunda otomatik olarak prisma generate da çalışır. 
    cd C:\Users\User\Desktop\hootel-booking-mcp-server
npm install
  2. Client bağımlılıkları: 
    npm install --prefix client
  3. Sadece yeni / boş bir veritabanıysa tabloları oluştur. Senin Neon DB'nde tablolar zaten var, bunu atlayabilirsin. 
    npm run db:migrate

    Seed (örnek odalar) gerekmez: sunucu açılırken oda tablosu boşsa odaları kendisi ekler.

Her gün çalıştırma — 2 terminal

  1. Terminal 1 — backend (build gerektirmez, TypeScript'i direkt çalıştırır): 
    npm run start:dev
    Kontrol: tarayıcıda http://localhost:3001/api/health → "status":"ok", "database":"connected"
  2. Terminal 2 — frontend: 
    cd client
npm run dev
    Aç: http://localhost:3000. Vite, /api isteklerini otomatik olarak localhost:3001'e yönlendirir (client/vite.config.ts).
README'de iki yanlış varREADME client için 5173 portunu yazıyor ama vite.config.ts içinde port 3000. Ayrıca "Option B"de stdio MCP için npm start yazıyor. Aslında npm start HTTP API'yi başlatır, stdio MCP server'ı npm run start:mcp başlatır.

Kısayol: backend'i hiç çalıştırmadan client'ı canlı Render'a bağla

client/.env.local dosyası oluştur. Bu dosya git'e gitmez (.gitignore içinde .env.* var).

VITE_API_BASE_URL=https://hootel-booking-mcp-server.onrender.com

Sonra sadece cd client && npm run dev. Backend'de CORS açık olduğu için doğrudan çalışır. Lokal backend'e geri dönmek için dosyayı sil.

Production gibi çalıştırmak (Render'ın yaptığının aynısı)

npm run build      # prisma generate + tsc → dist/
npm start          # node dist/src/api/server.js

Ya da Render'da Build Command'ı npm install && npm run build && npm run db:migrate yap.

3 · Frontend → Netlify

Render'dan sonraki adım bu. Netlify'ın tüm ayarı repoda zaten hazır: kökteki netlify.toml dosyası.

[build]
  base    = "client"          # client klasöründe çalış
  publish = "dist"            # vite build çıktısı
  command = "npm run build"

[[redirects]]                 # /api/* isteklerini Render'a ilet
  from = "/api/*"
  to   = "https://hootel-booking-mcp-server.onrender.com/api/:splat"
  status = 200

[[redirects]]                 # React SPA: her yolu index.html'e ver
  from = "/*"
  to   = "/index.html"
  status = 200

Yani tarayıcı netlify-siten.app/api/rooms istediğinde Netlify bunu arka planda Render'a iletir. Bu yüzden client'ta Render URL'i yazmana ve CORS ile uğraşmana gerek kalmaz.

Siteyi kurmak (ilk defa / tekrar)

  1. app.netlify.com → Add new site → Import an existing project
  2. GitHub → bbaymistery/hotel_mcp_2_updated
  3. Build ayarları ekranı netlify.toml'dan otomatik dolar: Base client, Build npm run build, Publish client/dist. Dokunma.
  4. Environment variable gerekmez. VITE_API_BASE_URL'i boş bırak ki istekler redirect üzerinden gitsin.
  5. Deploy. Bitince https://<site-adın>.netlify.app açılır. İstersen Site configuration → Change site name ile adı değiştirebilirsin.
Render URL'i değişirseRender servisini farklı bir isimle yeniden kurduysan, yeni URL'i iki yerde güncelle: netlify.toml ve client/public/_redirects. Sonra push et.
Neden iki dosya?netlify.toml asıl ayar. client/public/_redirects yedek: biri client/dist klasörünü Netlify'a elle sürükleyip bırakırsa (drag & drop deploy) o zaman da redirect çalışsın diye.

5 · Kendi projende MCP olarak kullanmak

Eklemen gereken URL bu (Streamable HTTP transport):

https://hootel-booking-mcp-server.onrender.com/mcp

Sonunda /mcp olmalı. /api/... değil. Bu endpoint src/api/app.ts içinde tanımlı.

Bu MCP'nin verdiği tool'lar

ToolParametrelerNe yapar
check_availabilitycheck_in, check_out (YYYY-MM-DD), guests (1–10)Boş odaları, kapasiteyi ve toplam fiyatı (USD) döner
book_roomroom_id, customer_name, customer_email, check_in, check_out, guests, opsiyonel idempotency_keyRezervasiya yapar (double booking korumalı, commit sonrası webhook)

Kendi Node/TS uygulamandan MCP client olarak bağlanmak (npm i @modelcontextprotocol/sdk):

import { Client } from '@modelcontextprotocol/sdk/client/index.js';
import { StreamableHTTPClientTransport } from '@modelcontextprotocol/sdk/client/streamableHttp.js';

const client = new Client({ name: 'my-app', version: '1.0.0' });
await client.connect(new StreamableHTTPClientTransport(
  new URL('https://hootel-booking-mcp-server.onrender.com/mcp')
));

const { tools } = await client.listTools();          // tools/list
console.log(tools.map(t => t.name));                // ['check_availability', 'book_room']

const res = await client.callTool({                  // tools/call
  name: 'check_availability',
  arguments: { check_in: '2026-12-10', check_out: '2026-12-12', guests: 2 }
});
console.log(res.content);

Projedeki src/services/mcp-client.service.ts aynı şeyi yapıyor (Gemini chat için), ama orada InMemory transport kullanılıyor.
